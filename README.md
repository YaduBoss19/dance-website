# Dr. Malavika Sunil — Private Dance & Music Studio

> **Move. Learn. Master.**  
> A premium personal-brand platform for online, one-to-one classical dance and vocal music coaching, mentored directly by **Dr. Malavika M. Sunil** (CCRT Scholar, 21-yr Bharatanatyam disciple, Carnatic vocalist, and MBBS physician).

## 🌟 Key Features

- **Personal 1-to-1 Coaching:** Tailored private lessons with undivided personal attention, flexible international scheduling, and custom video feedback.
- **The 8 Disciplines & Services:**
  1. *Online Bharatanatyam Diploma Programme* (Accredited classical Margam syllabus)
  2. *Online Carnatic Vocal Music Classes* (Shruti, Swara, Ragas, Kritis, Keerthanas)
  3. *Online Semi-Classical and Bollywood Dance* (Lyrical, expressive choreography)
  4. *Online Yoga and Fitness for Dancers* (Physician-guided kinesiology & alignment)
  5. *Personalised Dance Choreography* (Custom choreography for your song of choice)
  6. *Stage Performance Choreography* (Solo & group stage shows, cultural galas)
  7. *One-Day Institutional Dance Workshops* (Universities & masterclasses)
  8. *Five-Day Intensive Dance Residencies*
- **Museum-Grade Visual Design:**
  - Charcoal (`#151515`), Warm Ivory (`#F5F0E8`), Muted Gold (`#B99A63`), Stone Grey (`#A9A49D`).
  - Editorial serif headings (`Cormorant Garamond`) and modern clean sans-serif body (`Plus Jakarta Sans`).
  - Museum-grade gold matting frames with ambient drop shadows.
- **Interactive Studio Intro Video:** Embedded cinematic player for Dr. Malavika's introduction video.
- **Mobile-First Experience:** Sticky bottom action bar with 1-tap WhatsApp chat, direct call, lesson navigator, and trial booking.
- **Private Instructor Dashboard:** Password-protected portal (`admin123`) to review student leads, schedule sessions, and connect directly on WhatsApp.

## 🚀 Getting Started

### 1. Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### 2. Installation
```bash
git clone https://github.com/YaduBoss19/dance-website.git
cd dance-website
npm install
```

### 3. Development Server
```bash
npm run dev
```
Open [http://localhost:5174/](http://localhost:5174/) in your browser.

### 4. Production Build
```bash
npm run build
```
Creates an optimized production bundle in the `dist/` directory.

### 5. Automated GitHub Pages Deployment
A GitHub Actions workflow is included at `.github/workflows/deploy.yml` which automatically builds and deploys the site to GitHub Pages on every push to the `main` branch.

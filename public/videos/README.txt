DANCINGRAGAS — PUBLIC VIDEOS ARCHIVE

ORGANIZATION:
1. /performances/  -> Full stage recordings, recitals, and classical concert videos
2. /workshops/     -> Student masterclasses, adavu drills, and workshop reels

HOW TO UPDATE / CHANGE VIDEOS:
- Replace any video with an MP4 file with the same filename.
- Standard Video Format: MP4 format with H.264 video codec and AAC audio.
- Keep video file sizes optimized (typically 3MB - 12MB) for instant loading on mobile and desktop web browsers.

ZERO-CROPPING VIDEO PLAYER (Approach B):
The website renders all video clips in full uncropped letterbox mode (object-contain)
with ambient blurred background framing, so full body postures, mudras, and facial
expressions are NEVER cropped during playback!

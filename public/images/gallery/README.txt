HOW TO UPDATE / CHANGE PHOTOS:
1. To replace an existing performance thumbnail:
   Simply drop your new photo into this folder with the same filename
   (e.g., 'gallery_01.jpg', 'gallery_02.jpg', etc.).

2. Or add a new photo with any name:
   Then update 'thumbnail' in 'src/components/CinematicReelsShowcase.jsx'.

HOW TO UPDATE / CHANGE PHOTOS:
1. To replace an existing Instagram post/reel card photo:
   Simply drop your new photo into this folder with the same filename
   (e.g., 'insta_01.jpg', 'insta_02.jpg', etc.).

2. Or add a new photo with any name:
   Then update 'imageUrl' in 'src/components/CinematicReelsShowcase.jsx'.

STANDARD FILE NAMES:
- insta_01.jpg  -> Live Stage Bharatanatyam Recital
- insta_02.jpg  -> International Classical Workshop
- insta_03.jpg  -> Auditorium Stage Choreography
- insta_04.jpg  -> Carnatic Classical Shruti Practice
- insta_05.jpg  -> Temple Silhouette & Hastha Mudras
- insta_06.jpg  -> Youth Classical Dance Workshop

- insta_09.jpg  -> Weekend Classical Dance Intensive

TIPS:
- Any standard image format works (.jpg, .jpeg, .png, .webp).
- The website uses 'Approach B' (Full uncropped letterbox with luxury ambient 
  backdrop), meaning every Instagram post card displays the complete photo without cropping!

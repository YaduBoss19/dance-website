HOW TO UPDATE / CHANGE PHOTOS:
1. To replace an existing course or service photo:
   Simply drop your new photo into this folder with the EXACT same filename
   (e.g., replace 'diploma_bharatanatyam.jpg' with your new picture).

2. Or add a new photo with any name:
   Then update the file path in 'src/data/initialData.js'.

STANDARD FILE NAMES:
- diploma_bharatanatyam.jpg    -> Online Bharatanatyam Diploma Course
- non_diploma_bharatanatyam.jpg-> Online Bharatanatyam Non-Diploma Classes
- carnatic_music.jpg           -> Online Carnatic Music Classes
- bollywood_dance.jpg          -> Online Semi-Classical Bollywood Dance
- fitness_program.jpg          -> 60-Day Fitness Program
- service_stage_show.jpg       -> Event-Based Stage Show Choreography
- service_wedding.jpg          -> Wedding Choreography
- service_workshop_1day.jpg    -> One-Day Dance Workshops
- service_workshop_3day.jpg    -> Three-Day Dance Workshops
- service_competition.jpg      -> Competition-Based Choreography
- service_corporate.jpg        -> Corporate Event Stage Shows

TIPS:
- Any standard image format works (.jpg, .jpeg, .png, .webp).
- The website uses 'Approach B' (Full uncropped letterbox with luxury ambient 
  backdrop), meaning your photo is 100% visible and FACES WILL NEVER BE CROPPED!
